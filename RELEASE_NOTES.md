# Relay IPTV 0.1.6

- **Manage categories:** one page in Settings to put categories in your order and hide the ones you don't watch, for Live TV, Movies and Series. Tick several, or filter (several words, *Containing* or *Not containing*) and tick everything listed, then move them in one go. On TV, **Move with remote** lifts the ticked categories into one block: Up/Down moves it a row, Channel up/down a page, OK drops it. Hold OK on any category for quick Move to top, up, down or bottom
- **Loading screen:** channels, movies and series count up as they load, each with its own progress bar
- **Remote-friendly text boxes:** moving onto a box only highlights it; press OK to type, so the keyboard no longer pops up as you pass
- **Player:** Back first hides the controls and a second Back leaves; a Mute button in both players
- **Fixes:** holding OK for the channel menu no longer picks its first item by itself; text boxes on large tablets open on tap

Already on an earlier version? The app offers this update itself — choose **Install now** when asked.
